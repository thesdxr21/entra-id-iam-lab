# entra-id-iam-lab
Microsoft Entra ID IAM Engineering Labs — Zero Trust | DoD IL2, IL4, IL5 | NIST 800-53

A seven-lab series demonstrating hands-on identity and access 
management engineering capability mapped to DoD IL2, IL4, IL5 requirements 
and NIST 800-53 controls.

## Scope
- Tenant: oyainvestments.onmicrosoft.com
- Labs: RBAC, Conditional Access, Federation, Zero Trust, 
  DoD Compliance, Compliance Reporting
- Frameworks: NIST 800-53, CMMC, Zero Trust, DoD IL2/IL4/IL5
