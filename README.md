# IAM Engineer Lab Portfolio

**Microsoft Entra ID | Zero Trust | DoD IL2/IL4/IL5 | NIST 800-53**

A seven-lab series demonstrating hands-on IAM engineering capability 
mapped to DoD IL4 requirements and NIST 800-53 Moderate baseline controls.

## Scope
- Platform: Microsoft Entra ID
- Frameworks: NIST 800-53, CMMC, Zero Trust, DoD IL2/IL4/IL5
- Certifications: SC-300

## Key Controls Implemented
- Layered Conditional Access policy stack with risk-based enforcement
- PIM just-in-time privileged access with 2-hour activation windows
- SAML 2.0 and OIDC federation with live ID token validation
- Named locations and geographic access restrictions
- Entitlement management with governed access lifecycle
- Log Analytics workspace for audit log collection and KQL querying
